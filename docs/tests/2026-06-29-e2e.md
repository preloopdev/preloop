## Known gaps observed

1. **Timeline/log endpoint fidelity**: Runner reports "Canceled" for completed jobs because timeline/log endpoints return synthetic/unmatched responses. This is tracked in `fidelity-gap.md`.
2. **In-memory state**: Server state lost on restart (expected — no persistence layer yet).
3. **221 upstream fixtures skipped**: Mostly Azure Pipelines and unsupported YAML constructs (e.g. reusable workflows with `uses:` in sub-workflows).
