## Remaining gaps

1. **Runner self-reports "Canceled"**: After completing a job, the runner reports "Canceled" in its own log even though the step executed. The aksh server correctly records the job as success. This prevents the runner from looping back to poll for additional jobs in the same session. Root cause: timeline/log endpoint response shapes need further wire-level fidelity matching against the AzDO protocol contract.
2. **In-memory state**: Server state lost on restart (no persistence layer yet).
3. **Azure Pipelines fixtures**: Removed from `fixtures/upstream-workflows/` (205 files — irrelevant to GitHub Actions). Remaining 15 skips are `action.yml`, non-yml/yaml, or YAML without `jobs:`.
