# Benchmarks — aksh-runner vs Official Runner

Generated by `scripts/bench-runner.sh`.

## Size

| Component | aksh-runner (Rust) | Official runner (C#/.NET) | Ratio |
|-----------|-------------------|--------------------------|-------|
| Binary / install dir | **5.3 MB** | 435 MB | **82x smaller** |
| Without externals (node) | 5.3 MB | ~85 MB (est.) | ~16x smaller |

The Rust binary is a single static executable. The official runner includes the .NET runtime, hundreds of DLLs, and pre-bundled Node.js externals.

## Cold start

| Metric | aksh-runner | Official runner |
|--------|-------------|-----------------|
| `--version` wall time | **4 ms** | ~200 ms |

The Rust binary has no runtime initialization overhead (no CLR JIT, no assembly loading).

## Methodology

Benchmarks run against local aksh deliberately — it is a controlled, network-noise-free substrate where both runners face the identical server, isolating runner overhead.

```sh
# Reproduce
just build-runner
./scripts/bench-runner.sh --json
cat bench-results.json
```
