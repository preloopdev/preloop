## Dependency notes

Plan 001 is intentionally phased:

1. instrumentation;
2. local Actions cache and toolcache correctness;
3. immutable action/image/VM supply caches;
4. self-hosted durable storage;
5. managed multi-tenant controls.

Do not start managed storage before server-derived namespaces, streaming transfers, and local correctness exist. Scaling the current in-memory/full-buffer data path would amplify correctness and security defects.

## Findings considered and rejected

- One shared writable cache mount for every VM: rejected because of corruption/trust risk and measured virtiofs fork stalls.
- Universal golden containing undeclared toolchains: rejected because it breaks workflow portability and invalidates large images too often.
- Whole-workspace reuse: rejected because stale files, cross-ref contamination, and secret leakage outweigh latency gains.
- Cross-tenant mutable cache deduplication exposed at the logical layer: rejected because it creates poisoning and information-oracle risks.
